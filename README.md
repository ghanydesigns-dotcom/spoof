# SPOOF website

Static site for GitHub Pages. Upload `index.html` and the `assets` folder to the repo root, then turn on Pages (Settings → Pages → Deploy from branch → main / root).

The G.A.R.V.I.S download button links to the `.ccx` on Google Drive. Clicks are counted anonymously on counterapi.dev (namespace `spoof-by-g`, key `garvis-download`) and added to a base of 50, shown as "N+ Downloads" under the Download button (`BASE` in the script). To change the file, edit the `href` of `#gDl` in `index.html`.
